# Grammatica — Italian Verbs & Grammar

A single-file study app for Italian: verb conjugation reference, a practice/test mode, and a colour-coded grammar guide. Designed for iPad — add it to the Home Screen to run full-screen and offline.

## Live site
Once GitHub Pages is enabled: `https://<your-username>.github.io/<repo-name>/`

## What's inside
- **Reference** — regular (-are/-ere/-ire) and common irregular verbs across present, passato prossimo, imperfetto, futuro, condizionale and congiuntivo. Colour-coded endings with shared patterns highlighted; tap any verb to see all tenses; tap 🔈 to hear it.
- **Practice** — type or multiple-choice drills, an accent helper bar, saved score/streak, and a "review my mistakes" pool.
- **Grammar** — sectioned guide from foundations (gender, articles, agreement) through to harder concepts (passato prossimo vs imperfetto).

## Files
- `index.html` — the app (served by GitHub Pages at the site root).
- `italian-grammar.html` — identical copy; edit either, but keep `index.html` as the one Pages serves.

Everything runs client-side; there is no build step and no dependencies.
